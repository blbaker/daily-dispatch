React Native Impeller engine, from react-native-impeller-platform 0.3.1

The desktop builds run on the engine binary and libraries in the
@blbaker/react-native-impeller-platform-engine-<os>-<cpu> npm package. Neither
that package nor react-native-impeller-platform ships a license file. This
note comes from the project's repository,
https://github.com/blbaker/react-native-impeller-platform, at tag v0.3.1
(commit f9d14e0984895c4f8f2f07d17f226e147d970662). The project's own MIT
license is printed above this note.

Components the repository's THIRD_PARTY_NOTICES.md lists, with the license
it gives for each:

- Flutter / Impeller: BSD-3-Clause. The rendering engine, linked from a
  pinned Impeller SDK build.
- React Native C++ core (0.86.2): MIT. Its license text is in the
  react-native entry of this file.
- Hermes: MIT. The JavaScript engine, built from source.
- GLFW (3.4): Zlib. Windowing and input on the desktop GL backends.
- ANGLE: BSD-3-Clause. Runs GLES on Metal (macOS) and Direct3D 11 (Windows).
- Boost (1.83.0): BSL-1.0. Used by a few engine modules.

The engine build at the same tag also compiles in components that the
repository's notices do not list (engine/cmake/ReactCommonDeps.cmake,
engine/CMakeLists.txt and engine/third_party): folly v2024.11.18.00,
glog v0.6.0, fmt 12.1.0, double-conversion v3.3.0, fast_float v8.0.0,
OpenSSL 3.2.1 (Windows build), react-native-svg 15.15.5, the Khronos EGL and
GLES headers, and stb. Their license texts are not in this file yet.

The license texts below come from each project's repository: Flutter at
commit 114eb184d66d7ca136d89eb8ec09f61aff265062 (the engine's IMPELLER_SHA),
GLFW at tag 3.4, Boost at tag boost-1.83.0, and Hermes and ANGLE at their
main branches (commits 17b37301da5d and e63337a7cfc6).
